# 🎓 منصة إنجاز - رفيق المتابعة والتميز الدراسي

موقع ويب تفاعلي حديث صُمم خصيصاً لمتابعة دراسة أختك في الثانوية، مع معيار تفوق صارم (95% فأعلى)، وتتبع دقيق للدروس المتوقف عندها حالياً، وجدول الحصص الخاصة، وقسم ذكي لتحليل ومراجعة أوجه القصور بالتعاون مع Google Gemini / NotebookLM.

---

## 🌟 الميزات الرئيسية

1. **تبويب مخصص لكل مادة (5 مواد أساسية)**:
   - فهرس شامل مقسم لوحدات وفصول ودروس.
   - **علامة خضراء بارزة ونابضة (🟢 متوقفين عنده حالياً)** توضح بالضبط الدرس الذي تقف عنده في كل مادة بضغطة زر واحدة.
   - نسبة إنجاز وإتقان خاصة بكل مادة.

2. **نظام تقييم واختبار ذكي بمعيار 95%**:
   - إمكانية إجراء الاختبار خارجياً على **Google NotebookLM** أو **Gemini**.
   - تسجيل الدرجة (كنسبة مئوية أو درجة من مجموع) مع نسخ تقرير جيمناي لأوجه القصور.
   - **التقييم التلقائي**:
     - إذا كانت الدرجة **≥ 95%**: يُعتبر الدرس **مجتازاً ومتقناً بتفوق 🎉** مع احتفال بصري وتأكيد الإتقان.
     - إذا كانت الدرجة **< 95%**: يُصنف الدرس تلقائياً كـ **"⚠️ يحتاج مراجعة"** ويُرسل فوراً إلى "قسم المراجعات الذكية".

3. **قسم المراجعات الذكية (Smart Revision Hub)**:
   - يجمع تلقائياً كافة الدروس التي لم تحقق 95% عبر كل المواد.
   - يعرض بدقة نقاط الضعف والمفاهيم المطلوب مراجعتها التي تم استخراجها من تحليل جيمناي.
   - زر "إعادة الاختبار بعد المراجعة" للتحقق من إتقانها ورفع درجتها لمعيار التفوق.

4. **جدول مواعيد الدروس والحصص الخاصة**:
   - تقويم أسبوعي يعرض أيام الحصص، التوقيت، اسم المعلم، المكان (سنتر / أونلاين / منزل)، والملاحظات.
   - بطاقة بارزة تعرض موعد الحصة القادمة مباشرة في أعلى الصفحة الرئيسية.

5. **وضعان للاستخدام**:
   - 🛡️ **وضع الإشراف والتحكم (لك)**: يسمح بتعديل الفهرس، رصد نتائج الاختبارات، وتحديث مكان التوقف، وتعديل الجدول.
   - 🌸 **وضع أختي (مشاهدة وتحفيز)**: واجهة ملهمة وخالية من إمكانية التعديل بالخطأ لتشجيعها على الإنجاز.

6. **محرر الفهرس السريع واللصق الجماعي (Bulk Import)**:
   - تمهيداً لإرسال فهرس المواد لاحقاً، يمكنك ببساطة نسخ قائمة الدروس ولصقها دفعة واحدة ليقوم الموقع بإنشاء الفهرس فوراً!

7. **حفظ فوري ونسخ احتياطي**:
   - حفظ تلقائي للبيانات على المتصفح (LocalStorage).
   - زر تصدير (Backup) واستيراد (Restore) لملف JSON لضمان عدم ضياع أي بيانات ونقلها بين الأجهزة بسهولة.

## 🚀 طريقة التشغيل

### محلياً على جهازك:
```bash
cd study-tracker
npm run dev
```
الموقع سيعمل مباشرة على:
- جهازك: `http://localhost:3000`
- هاتفك أو أي جهاز على نفس شبكة الواي فاي: من خلال عنوان الـ Network IP الظاهر في الطرفية (مثال: `http://192.168.1.167:3000`).

### للرفع أونلاين مجاناً (Vercel / Netlify):
المشروع جاهز ومبني بالكامل في مجلد `dist`:
1. يمكنك رفع كود المشروع على GitHub وربطه بـ **Vercel** أو **Netlify** بضغطة زر مجاناً وبدون أي تكلفة.
2. أو سحب مجلد `dist` وإفلاته في **Netlify Drop** للحصول على رابط أونلاين فوري لمشاركته معها.
